# Changelog

All notable changes to Arkael Manager are documented in this file.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Features

**Monitor** - CPU frequency (Little and Big cluster), GPU, RAM, battery, governor, ZRAM, temperature, CPU / GPU / kernel info, terminal log.

**Tools** - CPU governor and max frequency, ZRAM size and compression algorithm, thermal control, GPU frequency control, IO scheduler, clean cache, screen saturation boost, graphics renderer, disable CPU vsync, keybox generator.

**Settings** - glass style, icon color theme, background color.

## [3.0] - 2026-10-20

### Changed
- Automatic releases: every push builds, signs, tags and publishes a new version
- In-app update checker (shows a dialog when a newer release is available)
- UI v4.2: animated banner rings, removed "Change Banner"
- UI v4 / v3 / v2: new layout, animated gauges, fading banner edge
- New Arkael Manager banner, app icon and chip-style icon
- Modern theme and fonts (Poppins, navy/orange), vector icons, glass cards
- Auto-sized battery text, restored tools icon
- Removed passkey and kernel check; app is always unlocked
- Renamed app and package to Arkael Manager (com.arkael.app)
