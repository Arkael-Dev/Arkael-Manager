# ai-agent

Repo kerja untuk Arkael-Ai-Agent (mode agent di Arkael Manager).

Agent bisa membaca dan menulis file di sini, lalu commit dan push ke branch
`feature/ai-agent`. Semua file teks di repo ini boleh diubah agent atas
perintah pengguna.

## Isi

- `scripts/` — skrip bantu agent
- `.github/workflows/` — pemeriksaan otomatis (syntax check)

## Aturan

1. Jangan simpan API key, token, atau data pribadi di repo.
2. Satu commit = satu perubahan yang jelas. Pesan commit bahasa Indonesia singkat.
3. Selalu push ke branch fitur, bukan `main`.
